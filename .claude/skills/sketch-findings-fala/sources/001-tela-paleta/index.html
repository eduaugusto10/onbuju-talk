F · Apagar figuras — 3 jeitos limpos

O badge ✕ vermelho e a caixinha de lixeira ficaram feios. Aqui três formas de apagar integradas à barra, sem adesivo de erro e sem remendo. Todas funcionam de verdade — escolha a que parece melhor.

opção 1 · escolhida ★

Tocar para tirar

As figuras ficam limpas, sem nenhum badge. Toque numa figura e ela some com uma animação suave. Para apagar tudo, um link discreto "limpar" aparece ao lado — só quando há figuras.

Toque numa figura para tirá-la.

opção 2

Apagar como num teclado

Um único botão ⌫ tira a última figura — igual a digitar. Segure o botão para limpar tudo. Um controle só, footprint igual ao do ✨, zero poluição. É o padrão de apps AAC de verdade.

⌫ tira a última. Segure ⌫ para limpar tudo.

opção 3

Modo editar

No uso normal as figuras ficam intocáveis — nada de remoção acidental. O botão "editar" faz aparecer um − em cada figura (estilo iOS, cinza discreto). Tocou, voltou ao normal.

"Editar" mostra um − discreto em cada figura.
